# Empresas

El módulo utiliza la base CouchDB `empresas` y el índice Mango `empresas-nit/por-nit`.

La estructura de los documentos, los campos obligatorios y opcionales y un ejemplo están en [la documentación de la base empresas](../../database/empresas/README.md).

El backend Rust crea la base y el índice automáticamente al iniciar.
